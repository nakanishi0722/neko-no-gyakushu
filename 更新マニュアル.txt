# 捨て猫の逆襲 サイト 更新マニュアル

キャスト・お知らせ・メニュー・写真は、**`data` フォルダのファイルを書き換えるだけ**で更新できます。
HTML（`index.html` など）を開く必要はありません。

---

## 1. フォルダの中身

```
index.html        TOPページ
cast.html         キャスト一覧
menu.html         メニュー
news.html         お知らせ
recruit.html      キャスト募集
404.html          ページが見つからないときの表示
data/
  cast.js         ← キャストを書き換える
  news.js         ← お知らせを書き換える
  menu.js         ← メニューを書き換える
  photos.js       ← TOPなどの大きな写真を設定する
img/
  cast/           ← キャストの写真を入れる
  news/           ← お知らせの写真を入れる
  photos/         ← TOPなどの大きな写真を入れる
  ogp.png         SNSでシェアされたときの画像
  favicon.svg ほか  ブラウザのタブに出るアイコン
css/ js/          見た目と動き（通常は触りません）
.htaccess         サーバーの設定（404ページ・表示の高速化）
robots.txt        検索エンジン向けの設定
```

**サーバーにアップロードしないもの：** `更新マニュアル.md`、`CLAUDE.md`

---

## 2. 書き換えるときの道具

- Windows の「メモ帳」、または無料の「Visual Studio Code」で開けます。
- 保存するときの文字コードは **UTF-8** にしてください（メモ帳の初期設定のままで大丈夫です）。
- Word では編集しないでください（記号が変わって動かなくなります）。

---

## 3. キャストを更新する（`data/cast.js`）

1人分はこの形です。

```js
  {
    name: "黒羽 ルナ",
    en: "Luna Kurobane",
    photo: "img/cast/luna.jpg",
    quote: "紅茶と映画の話なら任せて。ゆっくり語ろうね。",
    birthday: "10月31日",
    likes: "紅茶、古い映画、雨音",
    days: "火・木・土",
    top: true,
  },
```

| 項目 | 内容 |
| --- | --- |
| `name` | 名前 |
| `en` | 英字の名前（不要なら `""`） |
| `photo` | 写真のファイル名。空 `""` なら猫のシルエットが表示されます |
| `quote` | ひとこと自己PR。1行（30文字くらいまで）がおすすめです |
| `birthday` `likes` `days` | 誕生日・好きなもの・出勤。空 `""` の項目は表示されません |
| `top` | `true` にした人がTOPページに載ります（2人がおすすめ） |

- **追加する：** `{` から `},` までをコピーして、下に貼り付けて書き換えます。
- **削除する：** その人の `{` から `},` までを消します。
- **並び順：** ファイルの上から順に表示されます。
- **卒業したキャスト：** 削除してください。

---

## 4. お知らせを更新する（`data/news.js`）

```js
  {
    date: "2026-11-08",
    tag: "Event",
    title: "黒薔薇の夜会 ── 冬の限定衣装イベント開催",
    text: ["1段落目の文章", "2段落目の文章"],
    photo: "img/news/20261108.jpg",
    link: { url: "https://x.com/Neko_otr", label: "公式Xを見る" },
  },
```

| 項目 | 内容 |
| --- | --- |
| `date` | 日付。必ず `"2026-11-08"` の形（半角）で書きます |
| `tag` | 小さな赤いラベル（例：`Event` `Info` `New Cast` `Menu`） |
| `title` | タイトル |
| `text` | 本文。`[ "段落1", "段落2" ]` で段落が分かれます。不要なら `[]` |
| `photo` | 写真。切り抜かずに全体が表示されるので、チラシ画像もそのまま使えます。不要なら `""` |
| `link` | 「詳しく見る」リンク。不要なら `url: ""` のまま |

- **日付の新しい順に自動で並びます。** 新しいお知らせは、ファイルのどこに書いても大丈夫です。
- 一番新しいお知らせが大きく表示され、TOPページには新しい4件が載ります。
- 古いお知らせは、増えすぎたら消してください。

---

## 5. メニューを更新する（`data/menu.js`）

```js
  {
    en: "Signature", jp: "看板ドリンク", top: true,
    items: [
      { name: "傷跡のロゼ", en: "Scar Rosé", price: 1200, text: "説明文" },
    ],
  },
```

- `price` は数字で書くと「¥1,200」と表示されます。「¥600〜」など自由に書きたいときは `"¥600〜"` と書きます。
- `top: true` のカテゴリがTOPページに載ります（各カテゴリの上から3品）。
- 品目の追加・削除は、`{ name: … },` の1行をコピー・削除します。

---

## 6. ページの大きな写真（`data/photos.js`）

| 項目 | 表示される場所 |
| --- | --- |
| `main` | TOPの一番最初の大きな写真（縦長がおすすめ） |
| `concept` | TOP「Concept」の写真（横4：縦5） |
| `menu` | TOP「Menu」とメニューページの写真 |
| `recruit` | TOP「Recruit」と求人ページの背景（暗く重ねて表示されます） |

---

## 7. 写真の用意のしかた

- **形式：** JPG（`.jpg`）がおすすめ。PNG・WebP も使えます。
- **大きさ：** 横幅 1200〜1600px、1枚 500KB 以下が目安です。大きすぎると表示が遅くなります。
- **ファイル名：** 半角の英数字にしてください（例：`luna.jpg`、`20261108.jpg`）。日本語や空白は使わないでください。
- **形：**
  - **キャスト・TOPの大きな写真・Concept・Recruit**：枠いっぱいに自動で切り抜かれます。顔など大事な部分は写真の中央に寄せてください（キャストは縦長 横4：縦5 がおすすめ）。
  - **メニュー・お知らせの写真**：切り抜かずに**写真全体**を表示します（チラシや告知画像もそのまま使えます）。縦長・横長どちらでも大丈夫です。メニューページとお知らせページでは、写真をタップすると大きく表示されます。
- **写真を差し替えるとき：** 同じファイル名で上書きせず、**新しいファイル名**にしてください（例：`luna.jpg` → `luna2.jpg`）。同じ名前だと、見ている人のブラウザに古い写真が残ることがあります。

---

## 8. 書き換えたあとの確認

1. パソコンで `index.html`（または各ページ）をダブルクリックして、ブラウザで開きます。
2. 変更が表示されているか確認します。

**表示されない・ページの一部が空になったとき**は、書き方の間違いがほとんどです。次を確認してください。

- 文字が `"` と `"`（半角のダブルクォート）で囲まれているか（全角の `”` になっていないか）
- 1人分・1件分の最後の `},` の **`,`（カンマ）** が消えていないか
- `[` と `]`、`{` と `}` の数が合っているか
- 写真が出ないときは、`photo` のファイル名と、実際のファイル名（大文字・小文字・拡張子）が同じか

---

## 9. サーバーへのアップロード

- 書き換えたファイル（例：`data/news.js`）と、追加した写真だけをアップロードすれば反映されます。
- フォルダの構成は変えないでください。

---

## 10. 営業時間・住所・SNSを変えるとき

営業時間・住所・SNSのアカウントは、各HTMLファイルに直接書かれています。
変えるときは、テキストエディタの「すべてのファイルで検索・置換」で、次の6ファイルをまとめて書き換えてください。

`index.html` `cast.html` `menu.html` `news.html` `recruit.html` `404.html`

（TOPページの `index.html` には、検索エンジン向けの店舗情報〔`application/ld+json` の部分〕にも営業時間・住所があります。）
